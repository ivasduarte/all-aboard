# Glossary

**Terms, Expressions and Acronyms (TEA) must be organized alphabetically.**

Here's the table sorted alphabetically:

| **_TEA_** (EN)                 | **_TEA_** (PT)                   | **_Description_** (EN)                                                                                                         |  
|:-------------------------------|:---------------------------------|:-------------------------------------------------------------------------------------------------------------------------------|  
| **Application**                | **Aplicação**                    | A software program designed to perform specific tasks for the user.                                                            |  
| **ApplicationSession**         | **Sessão da Aplicação**         | A class that manages the overall application state and session information.                                                    |
| **Authentication**             | **Autenticação**                 | The process of verifying the identity of a user and their access rights to the system.                                         |
| **AuthenticationController**   | **Controlador de Autenticação**  | A controller class that manages user authentication processes.                                                                  |
| **AuthenticationUI**           | **Interface de Autenticação**    | A user interface class responsible for handling authentication interactions.                                                    |
| **Budget**                     | **Orçamento**                    | Financial plans that outline expected revenues and expenditures over a specific period.                                        |  
| **Building**                   | **Edifício**                     | A structure that can be constructed at a station to provide specific effects or capabilities.                                  |
| **BuildingType**               | **Tipo de Edifício**            | A template that defines the properties of a building, including its cost, effects, and availability year.                     |
| **Cargo**                      | **Carga**                        | Goods or materials transported by trains.                                                                                      |  
| **Cargo Analysis**             | **Análise de Carga**             | Analysis of cargo types, revenue correlation, and linear regression for business optimization.                                 |
| **Cargo Demand**               | **Demanda de carga**             | The amount of cargo a station needs to receive.                                                                                |  
| **Cargo Supply**               | **Fornecimento de Carga**        | The amount of cargo a station can provide.                                                                                     |  
| **CargoMode**                  | **Modo de Carga**               | The mode of operation for cargo transportation, such as loading or unloading.                                                  |
| **CargoType**                  | **Tipo de Carga**               | Specific categories of cargo including passengers, mail, coal, iron ore, steel, and cars.                                      |
| **Carriages**                  | **Carruagens**                   | The parts of a train that carry passengers or cargo.                                                                           |  
| **City**                       | **Cidade**                       | A populated area that can be placed on the map, consisting of a center position and house blocks.                             |  
| **Class**                      | **Classe**                       | A blueprint for creating objects, defining their properties.                                                                   |  
| **Date**                       | **Data**                        | A class that manages date and time information within the simulation.                                                          |
| **Depot**                      | **Depósito**                     | A type of station specialized in storing and maintaining trains.                                                               |
| **Diesel**                     | **Diesel**                       | A type of locomotive powered by a diesel engine.                                                                               |  
| **DTO**                        | **Objeto de Transferência de Dados** | A design pattern used to transfer data between different layers of the application.                                        |
| **Economic Radius**            | **Raio Econômico**               | The area of influence of a station, where cities and industries supply and demand cargo.                                       |  
| **Editor**                     | **Editor**                       | A user role with permissions to create and modify maps and scenarios.                                                         |
| **EditorUI**                   | **Interface do Editor**          | A user interface class for the editor role, providing map and scenario creation tools.                                         |
| **Electric**                   | **Elétrica**                     | A type of locomotive powered by electricity, requiring electrified railway tracks.                                             |  
| **Expenses**                   | **Despesas**                     | Costs incurred in running the railway system, including track maintenance, train maintenance, and fuel costs.                   |
| **Financial Results**          | **Resultados Financeiros**       | A record of financial performance including expenses and revenues for a specific period.                                      |
| **Historical Restrictions**    | **Restrições Históricas**        | Historical events that make sense in the scenario and change the operating conditions of the simulator.                        |  
| **House Block**                | **Bloco de Casa**               | A single block within a city's grid, identified by its x and y coordinates.                                                   |
| **Industry**                   | **Indústria**                    | A static element that produces or transforms resources.                                                                        |  
| **IndustryType**               | **Tipo de Indústria**           | A template that defines the properties and characteristics of an industry.                                                     |
| **Java**                       | **Java**                         | A high-level, object-oriented programming language widely used for building applications and systems.                          |  
| **JavaDOC**                    | **JavaDOC**                      | A tool for generating automatic documentation from comments in Java code.                                                      |  
| **Locomotive**                 | **Locomotiva**                   | The engine part of a train that provides the power to move the train along the tracks.                                         |  
| **LocomotiveModel**            | **Modelo de Locomotiva**        | Specific model of a locomotive with defined characteristics like fuel type, speed, and operational years.                      |
| **Locomotive Types**           | **Tipos de locomotivas**         | Different types of locomotives, such as steam, diesel, and electric.                                                           |  
| **LocomotiveType**             | **Tipo de Locomotiva**          | Categories of locomotives including steam, diesel, and electric types.                                                         |
| **MainMenuUI**                 | **Interface do Menu Principal**  | The main menu interface that provides access to different application features.                                                |
| **MaintenanceRouteFinder**     | **Localizador de Rota de Manutenção** | A system component that finds optimal routes for railway maintenance operations.                                    |
| **Map**                        | **Mapa**                         | The playable area where cities, industries, and stations are placed.                                                           |  
| **MapLoad**                    | **Carregamento de Mapa**        | The process of loading map data from a saved file.                                                                             |
| **MapSave**                    | **Salvamento de Mapa**          | The process of saving map data to a file for later use.                                                                        |
| **MenuItem**                   | **Item de Menu**                | A menu option that represents a specific action or feature in the application.                                                 |
| **Mixed Industries**           | **Indústrias Mistas**            | Industries that combine characteristics of different sectors.                                                                  |  
| **Object**                     | **Objeto**                       | An instance of a class that encapsulates data and behavior.                                                                    |  
| **Object-Oriented (OO)**       | **Orientação a Objetos (OO)**    | A programming paradigm that organizes software into objects and classes.                                                       |  
| **Password**                   | **Senha**                       | A security credential used for user authentication.                                                                            |
| **PerformanceTesting**         | **Teste de Desempenho**         | A system component that evaluates and reports on the performance of various simulation features.                               |
| **Player**                     | **Jogador**                      | The user interacting with the simulation.                                                                                      |  
| **PlayerUI**                   | **Interface do Jogador**        | A user interface class for the player role, providing game interaction tools.                                                  |
| **PointOfRoute**               | **Ponto de Rota**               | A specific point along a train route, including position and station information.                                              |
| **PortBehavior**               | **Comportamento de Porto**      | A specialized behavior for port-type industries in the simulation.                                                             |
| **Primary Sector Industries**  | **Indústrias do setor primário** | Industries that generate natural resources, such as mines and farms.                                                           |  
| **Product Owner**              | **Proprietário do Produto**      | The person responsible for defining priorities and ensuring the product meets user needs.                                      |
| **Railway**                    | **Ferrovia**                     | A system of tracks, stations, and trains used for transporting goods and passengers.                                           |  
| **RailwayConnectivity**        | **Conectividade Ferroviária**   | A system component that verifies the connectivity between railway stations.                                                    |
| **RegularStation**             | **Estação Regular**             | A standard type of station that handles both passenger and cargo operations.                                                   |
| **Restrictions**               | **Restrições**                  | A class that manages various types of restrictions in the simulation (historical, technological, temporal).                     |
| **Revenues**                   | **Receitas**                    | Income generated from cargo deliveries and other railway operations.                                                           |
| **Route**                      | **Rota**                         | The path the train will take.                                                                                                  |  
| **RouteAnalysis**              | **Análise de Rota**             | Analysis of routes including shortest path calculations and maintenance route optimization.                                    |
| **Scenario**                   | **Cenário**                      | A specific configuration of the simulation including time, technological, and historical restrictions.                         |
| **ScenarioLoad**               | **Carregamento de Cenário**     | The process of loading scenario data from a saved file.                                                                        |
| **ScenarioSave**               | **Salvamento de Cenário**       | The process of saving scenario data to a file for later use.                                                                   |
| **ShortestRouteFinder**        | **Localizador de Rota Mais Curta** | A system component that calculates the shortest path between stations, considering required stops.                           |
| **Simulator**                  | **Simulador**                    | A software tool that replicates real-world processes or systems.                                                               |  
| **Simulator Operation**        | **Operação do Simulador**        | The process of running the simulator, allowing the user to interact with the behavior of the system under different conditions |  
| **SimulationLoad**             | **Carregamento de Simulação**   | The process of loading simulation data from a saved file.                                                                      |
| **SimulationSave**             | **Salvamento de Simulação**     | The process of saving simulation data to a file for later use.                                                                 |
| **Station**                    | **Estação**                      | A location where trains stop to load or unload cargo and passengers.                                                           |  
| **StationStatistics**          | **Estatísticas da Estação**     | Data about station performance including average profit, passenger arrivals, and cargo distribution.                           |
| **StationType**                | **Tipo de Estação**             | Categories of stations with different characteristics and capabilities.                                                        |
| **StationUpgradeService**      | **Serviço de Atualização de Estação** | A service class that handles the business logic for station upgrades.                                                  |
| **Steam**                      | **Vapor**                        | A type of locomotive powered by steam, typically using coal or wood as fuel.                                                   |  
| **Technological Restrictions** | **Restrições Tecnológicas**      | Such as types of locomotives available in the scenario.                                                                        |  
| **Terminal**                   | **Terminal**                     | A type of station that serves as an endpoint for train routes.                                                                 |
| **Time Restrictions**          | **Restrições Temporais**         | The period in which the simulation will take place.                                                                            |  
| **Track**                      | **Trilho**                       | The metal rails on which trains run.                                                                                           |  
| **Train**                      | **Comboio**                      | A vehicle composed of locomotives and carriages, used to transport cargo or passengers.                                        |  
| **Train Simulator**            | **Simulador de Comboios**        | A specific type of simulator focused on the operation and management of trains.                                                |  
| **Transforming Industries**    | **Indústrias de transformação**  | Industries that process raw materials into finished products.                                                                  |  
| **Unit Test**                  | **Teste unitário**               | A test that verifies the functionality of a unit of code.                                                                      |  
| **UpgradeAStationController**  | **Controlador de Atualização de Estação** | A controller class that coordinates the station upgrade process.                                                      |
| **UpgradeAStationUI**          | **Interface de Atualização de Estação** | A user interface class responsible for displaying and handling station upgrade interactions.                           |
| **UpgradeStationService**      | **Serviço de Atualização de Estação** | A service class that handles the business logic for station upgrades.                                                  |
| **User**                       | **Usuário**                     | A class that represents a user in the system, containing authentication and role information.                                  |
| **UserSession**                | **Sessão de Usuário**           | A class that manages the current user's session information and state.                                                         |
| **YearFinancialResults**       | **Resultados Financeiros Anuais**| Annual financial performance including expenses and revenues.                                                                 |
